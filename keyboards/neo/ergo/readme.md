# neo ergo wired - PCB

An Alice style board with arrowkeys.

* Keyboard Maintainer: [NEO Studio](https://github.com/owlab-git)
* Hardware Supported: neo ergo wired PCB

The `anokfireball` keymap is maintained in the external `qmk_userspace` repository. Configure `user.overlay_dir` to its path before using these build commands.

Make example for this keyboard (after setting up your build environment):

    make neo/ergo:anokfireball

Flashing example for this keyboard:

    make neo/ergo:anokfireball:flash

**Reset Key**: Hold down the key located at *K00* while plugging in the keyboard.

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
